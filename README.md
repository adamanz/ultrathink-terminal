# ULTRATHINK Terminal

A mysterious terminal-style application portal for the exclusive ULTRATHINK AI builders community. Built with React, Vite, and Express.

## Features

- **Terminal Aesthetic**: Green phosphor text, scan lines, and glitch effects
- **Magic Word System**: Hidden references to "ultrathink" as a magic word that unlocks enhanced capabilities
- **Mobile Responsive**: Fully responsive design that adapts to all screen sizes
- **Application System**: Backend API to capture and store applications
- **Easter Eggs**: Console messages and special animations for those who know the secret

## The Magic Word

The site cleverly references that "ultrathink" is a special word that allocates more "thinking budget" - a fun meta-reference for those who understand its significance in AI systems.

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/ultrathink-terminal.git
cd ultrathink-terminal

# Install dependencies
npm install
```

## Running the Application

```bash
# Start the backend server (port 5000)
npm run server

# In another terminal, start the frontend (port 3000)
npm run dev

# Or run both together
npm start
```
